Downloads & Setup Guide

1. Download Local Agent

The Python agent that does the actual file analysis.

Installation Steps

  1. Download the agent: 
    # Clone or download the agent folder
cd agent
pip install -r requirements.txt
  2. Set your OpenAI API key: 
    # Linux/Mac
export OPENAI_API_KEY=your_api_key_here

# Windows
set OPENAI_API_KEY=your_api_key_here

# Or create a .env file in the agent directory:
# OPENAI_API_KEY=your_api_key_here
  3. Test it: 
    python agent.py /path/to/your/file.py

2. Download VS Code Extension

Integrate TraceMind directly into VS Code.

📖 For complete step-by-step instructions, see: Full Installation Guide

Quick Installation Steps

  1. Install the agent first (see Step 1 above)
  2. Package the extension (if building from source): 
    cd vscode-extension
npm install -g vsce
npm install
vsce package
  3. Install in VS Code:
    • Open VS Code
    • Go to Extensions (Ctrl+Shift+X / Cmd+Shift+X)
    • Click "..." menu → "Install from VSIX..."
    • Select the generated tracemind-0.0.2.vsix file
    • Reload VS Code when prompted
  4. Or install via command line: 
    code --install-extension tracemind-0.0.2.vsix
  5. Configure API key: Create a .env file in the agent directory with: OPENAI_API_KEY=your_key

Usage: Press Ctrl+Shift+E (Windows/Linux) or Cmd+Shift+E (Mac) to explain any file!

Usage

Using VS Code Extension

  1. Open any file in VS Code
  2. Open Command Palette (Ctrl+Shift+P / Cmd+Shift+P)
  3. Type: TraceMind: Explain Current File
  4. View the explanation in the Output panel

Using Agent Directly

python agent.py /path/to/your/file.py

The explanation will be printed to the terminal.

Requirements

  • Python 3.8 or higher
  • VS Code 1.60.0 or higher (for extension)
  • OpenAI API key
  • Git repository (optional, for git history)

Cost Estimate

TraceMind uses OpenAI's gpt-4o-mini model:

  • ~$0.001-0.002 per file explanation
  • Very affordable for personal use
  • API calls only made when you request an explanation

Get your API key: https://platform.openai.com/api-keys

Troubleshooting

Common Issues

"OPENAI_API_KEY not set"
Make sure you've set the environment variable. Check with: echo $OPENAI_API_KEY (Linux/Mac) or echo %OPENAI_API_KEY% (Windows)
"agent.py not found"
Ensure the agent is installed and the path is correct. The extension looks for agent.py in ../agent/agent.py relative to the extension folder.
"Python not found"
Ensure Python 3 is installed and in your system PATH. Test with: python3 --version
"No git history found"
This is normal if the file isn't in a git repository. The agent will still work without git history.
