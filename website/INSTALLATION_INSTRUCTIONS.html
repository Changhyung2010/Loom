VS Code Extension - Installation Guide

Complete Installation Instructions

Follow these steps to install and use TraceMind in VS Code.

Prerequisites

Before installing, make sure you have:

  • VS Code 1.60.0+ - Download
  • Python 3.8+ - Download
  • Node.js (for packaging) - Download
  • OpenAI API Key - Get one here
  • Git (optional, for git history)

Step 1: Install the TraceMind Agent

The VS Code extension requires the TraceMind agent to be installed.

Download and Install

  1. Clone or download the repository: 
    git clone https://github.com/tracemind/tracemind-mvp.git
cd tracemind-mvp
    Or download the ZIP file and extract it.
  2. Navigate to the agent directory: 
    cd agent
  3. Install Python dependencies: 
    pip install -r requirements.txt
    This installs the required packages: openai and python-dotenv

Step 2: Configure Your OpenAI API Key

You need to set your OpenAI API key. Choose one method:

Method 1: .env File (Recommended)

  1. Navigate to the agent directory: 
    cd agent
  2. Create a .env file: 
    # Linux/Mac
nano .env

# Windows
notepad .env
  3. Add your API key: 
    OPENAI_API_KEY=your_api_key_here
  4. Save the file.

Method 2: Environment Variable

Linux/Mac:

export OPENAI_API_KEY=your_api_key_here

To make it permanent, add to ~/.zshrc or ~/.bashrc:

echo 'export OPENAI_API_KEY=your_api_key_here' >> ~/.zshrc
source ~/.zshrc

Windows (Command Prompt):

set OPENAI_API_KEY=your_api_key_here

Windows (PowerShell):

$env:OPENAI_API_KEY="your_api_key_here"

Get your API key: https://platform.openai.com/api-keys

Step 3: Test the Agent

Verify the agent works before installing the extension:

cd agent
python agent.py /path/to/any/code/file.py

You should see status messages and an AI-generated explanation. If this works, proceed to Step 4.

Step 4: Install the VS Code Extension

Package the Extension (if building from source)

cd vscode-extension
npm install -g vsce
npm install
vsce package

This creates a tracemind-0.0.2.vsix file.

Install in VS Code

Option A: Via UI (Easiest)

  1. Open VS Code
  2. Press Ctrl+Shift+X (Windows/Linux) or Cmd+Shift+X (Mac)
  3. Click the ... menu (three dots) in Extensions
  4. Select "Install from VSIX..."
  5. Navigate to and select tracemind-0.0.2.vsix
  6. Click "Install"
  7. Reload VS Code when prompted

Option B: Via Command Line

code --install-extension tracemind-0.0.2.vsix

Step 5: Verify Installation

  1. Open VS Code
  2. Go to Extensions (Ctrl+Shift+X / Cmd+Shift+X)
  3. Search for "TraceMind"
  4. Verify it's installed and enabled

Step 6: Using TraceMind

Method 1: Command Palette

  1. Open any code file in VS Code
  2. Press Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (Mac)
  3. Type "TraceMind: Explain File with TraceMind"
  4. Press Enter
  5. View the explanation in the webview panel

Method 2: Keyboard Shortcut

  1. Open any code file in VS Code
  2. Press Ctrl+Shift+E (Windows/Linux) or Cmd+Shift+E (Mac)
  3. The explanation appears automatically

Method 3: Context Menu

  1. Right-click on a file in the Explorer sidebar
  2. Select "Explain File with TraceMind"
  3. Or right-click in an open editor tab

Troubleshooting

"agent.py not found"
The extension looks for the agent at ../agent/agent.py relative to the extension folder. Make sure the agent is installed in the correct location, or modify the path in extension.js.
"Python not found"
Ensure Python 3.8+ is installed and in your PATH. Test with python3 --version. Add Python to your PATH if needed.
"API key error" or "OPENAI_API_KEY not set"
Check if the .env file exists in the agent directory with the correct API key. Or set it as an environment variable. Get your key from OpenAI.
"OpenAI package not installed"
Run: cd agent && pip install -r requirements.txt
Extension not working
Check VS Code Developer Console (Help → Toggle Developer Tools) for errors. Make sure the file is saved (not untitled). Verify the agent works from command line.
